# 問題09 ブランチ保護

共有するブランチには、強制 push を禁止する設定をかけることがある。その状態で reset による切り戻しがどうなるかを確かめる。リポジトリが Public であること。

## やること
1. GitHub の設定で、`develop` への強制 push を禁止するルールを作る
2. `pc` で `develop` を最新にし、「初期状態」に `git reset --hard` する
3. `git push --force-with-lease` を打つ
4. `pc` の `develop` を、GitHub の `develop` と同じ状態に戻す
5. 作ったルールを消す

## 問い
- Q1. 3.はどうなったか
- Q2. 保護されたブランチの内容を導入前に戻したいとき、どんな方法があるか
- Q3. 強制 push を禁止すると、どんな事故を防げるか
