# 問題10 コンフリクトを解消する

2人が同じ所を別々に変えた、という状況を1人で作る。

## やること
1. `pc` で `develop` を最新にし、作業用ブランチ `feature/conflict-a` を作る。`compose.staging.yml` の最後に `  app-a:` を追記して commit し、push する
2. `develop` に戻り、作業用ブランチ `feature/conflict-b` を作る。`compose.staging.yml` の最後に `  app-b:` を追記して commit し、push する
3. GitHub で、`feature/conflict-a` を `develop` に入れるプルリクエストを作り、マージする
4. GitHub で、`feature/conflict-b` を `develop` に入れるプルリクエストを作る(マージはまだしない)
5. `pc` の `feature/conflict-b` に、GitHub の `develop` を取り込み、コンフリクトを解消する(`app-a` と `app-b` の両方を残す)
6. push し、4.のプルリクエストをマージする

## 問い
- Q1. 4.のプルリクエストの画面には、何と表示されたか
- Q2. コンフリクトしたファイルの `<<<<<<<`・`=======`・`>>>>>>>` は、それぞれ何を表すか
- Q3. 解消したあと、何をすればコンフリクトが解決した扱いになるか
- Q4. コンフリクトを起こしにくくするには、ふだんどうすればよいか
