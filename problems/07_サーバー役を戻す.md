# 問題07 サーバー役を戻す

GitHub の `staging` は問題06で戻した。サーバー役はまだ、Trivy の1行が入ったままになっている。

## やること
1. `server` で `git pull --ff-only` を打ち、`compose.staging.yml` の中身を表示する
2. `git status -sb` を打つ
3. サーバー役を、GitHub の `staging` と同じ状態に戻す
4. `compose.staging.yml` の中身と `git status -sb` をもう一度確かめる

## 問い
- Q1. 1.の `git pull` は何と表示したか。ファイルは戻ったか
- Q2. 2.の表示の `ahead` は何を意味するか
- Q3. pull で戻らないのはなぜか
- Q4. 3.で使うコマンドは、commit していない変更があるとどうなるか
