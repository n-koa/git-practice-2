# 問題03 プルリクエストを出して取り込む

## やること
1. GitHub で、`feature/add-trivy` を `develop` に入れるプルリクエストを作る
2. 「Files changed」で変更の中身を確かめる
3. プルリクエストをマージする
4. マージで `develop` に入った commit の英数字を控える(問題8で同じ見方を使う)

## 問い
- Q1. プルリクエストを作る画面で、base は最初どのブランチになっていたか。そのまま作ると何が起きるか
- Q2. マージできる状態かどうかは、画面のどこで分かるか
- Q3. マージのあと、`develop` の commit は問題1のときからいくつ増えたか。その内訳は何か
- Q4. チームで作業するとき、自分のプルリクエストを自分でマージしない決まりにすることが多い。なぜか
