# 問題02 表示を読む

## やること
1. `pc` で `git log --oneline -3` を打つ
2. `develop` を最新にしてから、作業用ブランチ `feature/add-trivy` を作る
3. `compose.staging.yml` の最後に `  trivy:`(先頭に空白2つ)の1行を追記する
4. `git status --short` と `git diff` を打つ
5. 変更を「Trivyの定期診断を追加」という説明で commit し、push する

## 問い
- Q1. `git log --oneline` の先頭の英数字は何か。括弧の中の `HEAD -> …` や `origin/…` は何を表すか
- Q2. `git diff` の `a/` と `b/` は何か。先頭が `+` の行、空白の行はそれぞれ何か
- Q3. `git status --short` の表示は、`git add` の前と後でどう変わるか
- Q4. 作業用ブランチを作る前に、`develop` を最新にするのはなぜか
